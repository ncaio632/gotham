# ADR 001 — Customer-support response workflow

[README](../README.md)

## Context

A structured method for turning an inbound complaint into a context-specific response with an explicit operational owner.

## Decision

Treat response preparation and message delivery as separate operations.

## Consequences

Human review adds a handoff but preserves control over commitments and factual assertions.

## Evidence boundary

Editorial workflow and reference contracts. No autonomous sending engine, ticket integration or measured response SLA is claimed.
