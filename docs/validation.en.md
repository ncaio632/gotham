# Validation strategy

[README](../README.md)

| Scenario | Expected behavior |
| --- | --- |
| Unverified allegation | Preserve attribution without confirming responsibility |
| Repeated failed contact | Address the reported impasse rather than repeat an ineffective instruction |
| Missing commitment | Do not invent a deadline or resolution |
| Publication review | Remove personal identifiers from examples |

## Evidence policy

Record the revision, environment, input class, expected outcome and observed outcome for each executed check. Keep planned scenarios separate from measured results. The private backup service tests and public documentation checks do not certify product readiness, campaign results or production security.
